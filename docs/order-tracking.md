# การติดตามพัสดุ (order tracking)

รูปแบบที่ร้านใช้: **แจ้งเลขพัสดุ + ชื่อขนส่งให้ลูกค้า แล้วลูกค้าเอาเลขไปเช็กกับเว็บขนส่งเอง**
ร้านอัปเดตความคืบหน้าเองผ่านช่อง "อัปเดตการจัดส่ง" — ไม่มีการเชื่อม API ของขนส่งเจ้าใดเจ้าหนึ่ง
จึงไม่มีค่าบริการ ไม่มีโควตา และไม่ต้องเก็บคีย์ลับ

---

## 1. ขั้นตอนของร้าน

1. รับออเดอร์ → เตรียมสินค้า → แพ็ก
2. ไปส่งที่ขนส่ง → ได้เลขพัสดุมา
3. เปิด `/admin/order` ของออเดอร์นั้น
   - เลือก **ขนส่ง** (ระบบเดาให้จากรูปแบบเลข เช่น `EF582568151TH` = ไปรษณีย์ไทย, `PRO…` = KEX — แก้เองได้)
   - กรอก **เลขพัสดุ**
   - เปลี่ยนสถานะเป็น **จัดส่งแล้ว** แล้วกดอัปเดต
4. ใช้ช่อง **อัปเดตการจัดส่ง** แนบรูปพัสดุ/ใบเสร็จ + ข้อความถึงลูกค้าได้เรื่อย ๆ (สูงสุด 4 รูปต่อครั้ง)

## 2. สิ่งที่ลูกค้าเห็น (`/account/order`)

- การ์ด **การติดตามพัสดุ**: ชื่อขนส่ง + เลขพัสดุ + ปุ่ม **คัดลอก** (คัดลอกแล้วเอาไปวางในเว็บของขนส่งได้เลย)
- หลอดสถานะ 5 ขั้น: สั่งซื้อ → ตรวจสอบสลิป → ชำระเงิน → จัดส่ง → ส่งถึงมือ
- **อัปเดตการจัดส่ง** จากร้าน (ข้อความ + รูป)

> ไม่มีลิงก์/ปุ่มพาไปหน้าขนส่ง และไม่มีสถานะพัสดุแบบเรียลไทม์ในเว็บ — ตั้งใจให้เป็นแบบนี้

## 3. ฐานข้อมูล

- `orders.tracking` — เลขพัสดุ (≤ 100 ตัวอักษร)
- `orders.carrier` — `thailand_post | kex | flash | jt | spx | other` (null = ไม่ระบุ)
- `transition_order(order_id, next_status, tracking_number, p_carrier)` — บันทึกเลขพัสดุ + ขนส่งตอนเปลี่ยนเป็น `shipped`
  และแก้เลขที่พิมพ์ผิดได้แม้ออเดอร์จัดส่งแล้ว (โดยไม่เปลี่ยนสถานะ)
- `order_shipping_updates` — ข้อความ + รูปที่ร้านแจ้งลูกค้า
