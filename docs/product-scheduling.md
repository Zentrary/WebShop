# หมวดหมู่สินค้า + ตั้งเวลาเปิดขาย (Scheduled publishing)

> อัปเดต 24 พ.ย. 2026 — ใช้งานได้แล้วทั้งหลังบ้านและหน้าร้าน

## 1) เพิ่มหมวดหมู่ใหม่ได้จากฟอร์มสินค้าเลย

เดิม: ช่อง "หมวดหมู่" ในฟอร์มสินค้าเป็นช่องพิมพ์อิสระ การพิมพ์ชื่อใหม่ **ไม่** สร้างหมวดในตาราง `categories`
ผลคือชิปกรองที่หน้า `/shop` ไม่มีหมวดนั้น เพราะหน้าร้านอ่านหมวดจากตาราง `categories` เท่านั้น

ตอนนี้:

- ช่องหมวดหมู่มี **datalist** เด้งรายชื่อหมวดที่มีอยู่ให้เลือก/พิมพ์ซ้ำ
- พิมพ์ชื่อใหม่แล้วกด "บันทึกสินค้า" → ระบบสร้างแถวใน `categories` ให้อัตโนมัติ (ถ้าซ้ำจะไม่สร้างซ้ำ)
- ชิปที่หน้า `/shop` ขึ้นทันทีโดยไม่ต้องไปเพิ่มที่หน้า "หมวดหมู่" ก่อน

ยังจัดการหมวดแบบเต็มได้ที่ **หลังบ้าน → หมวดหมู่** (เพิ่ม / เปลี่ยนชื่อ / ลบ) เหมือนเดิม

## 2) ตั้งเวลาให้สินค้าขึ้นเว็บเอง

ในฟอร์มสินค้า **หลังบ้าน → สินค้า → เพิ่มสินค้า** มีของใหม่ 2 อย่าง:

| ฟิลด์ | ความหมาย |
| --- | --- |
| **ตั้งเวลาเปิดขาย** (`datetime-local`) | วันที่/เวลาที่สินค้าจะขึ้นเว็บเอง — เว้นว่าง = ขายทันที |
| **แสดง "เร็ว ๆ นี้" ก่อนถึงเวลา** (`show_soon`) | ให้ลูกค้าเห็นสินค้านี้ในแถบ "กำลังจะมา" ก่อนถึงเวลาหรือไม่ |

- ตารางสินค้าในหลังบ้านจะขึ้นป้าย **"ตั้งเวลา 27 พ.ย. 22:39"** แทนป้ายเปิด/ซ่อน เพื่อไม่ให้เข้าใจว่าสินค้าหาย
- สินค้าที่ตั้งเวลาไว้จะยังแก้ไข/ลบ/เปลี่ยนเวลาได้ตลอด

## 3) สิ่งที่ลูกค้าเห็น

- **ก่อนถึงเวลา**: สินค้าไม่โผล่ในรายการสินค้า (แสดงเฉพาะในแถบ "กำลังจะมา" ถ้าเปิด `show_soon`) พร้อมเวลานับถอยหลัง เช่น "เปิดขายใน 2 วัน 4 ชม."
- **ถึงเวลา**: ระบบเช็กทุก 30 วินาที — สินค้าย้ายเข้าไปอยู่ในรายการจริงเอง พร้อมแจ้งเตือน "สินค้าใหม่เข้าแล้ว: …" และหายจากแถบ "กำลังจะมา"
- **หลังขึ้นเว็บไม่เกิน 7 วัน**: การ์ดสินค้ามีป้าย **"ใหม่"** (สีเขียว) ให้ลูกค้าเห็นว่ามาใหม่

## 4) ทำไมต้องแก้ที่ฐานข้อมูล ไม่ใช่แค่ซ่อนที่หน้าจอ

ถ้าซ่อนแค่ในเบราว์เซอร์ ใครเปิด F12 ก็ยิง REST API ดึงสินค้าที่ยังไม่เปิดขายไปได้ (รวมราคา/สต็อก) จึงบังคับที่ชั้นข้อมูล:

```sql
-- products.publish_at, products.show_soon
-- policy อ่าน products: ลูกค้าเห็นเฉพาะ active AND (publish_at is null OR publish_at <= now())
--                    แอดมินยังเห็นทุกแถว
-- create_order_reserved_internal: ห้ามขายสินค้าที่ยังไม่ถึงเวลา
```
